# Spinitron Scraper
A python script that scrapes a station's spinitron now playing. I only tested this only on [Album 88](https://spinitron.com/WRAS/) and [KALX](https://widgets.spinitron.com/KALX/). I do not guarantee 100% compatibility with every station.

## Needed librarys 
1. Request 
2. BeautifulSoup
